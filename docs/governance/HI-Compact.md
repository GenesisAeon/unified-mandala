# Hybrid-Intelligenz (HI) – Compact v1.0

**Ziel:** Mensch + System treffen gemeinsam bessere Entscheidungen – nachvollziehbar, reversibel, lernfähig.

## 1) Prinzipien
- Transparenz (Ziel, Begründung, Unsicherheit, Fallback)
- Sicherheit zuerst (Shadow → Micro-Pilot → Rollout; harte Schranken & Undo)
- MRV by Design (ex-ante Erwartung, ex-post Ergebnis)
- Menschenwürde (Erklärbarkeit > rohe Performance)
- Resilienz (Offline & manuelle Handsteuerung)

## 2) Verbesserungs-Loop
SENSE → SYNTHESIZE → FORECAST → DECIDE → ACT → MEASURE → LEARN → SENSE …

## 3) Sicherheitskorridor
- Shadow Mode 2–4 Wochen
- Max ΔSetpoint ≤ 10 %/Tag, Rate-Limit, Hard-Caps
- Abort-Trigger bei Leitplankenverletzung → sofortiger Rollback

## 4) Verantwortlichkeiten
- Green Team (Wirksamkeit)
- Red Team (Risiken/Fehlalarme/soziale Folgen)

## 5) Dokumentation
Decision-Memo-ID, Experiment-Ticket, Post-Action-Review
