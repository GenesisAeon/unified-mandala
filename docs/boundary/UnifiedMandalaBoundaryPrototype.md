# UnifiedMandala Boundary Prototype

Dieses Dokument beschreibt das aus den Gesprächen abgeleitete Framework für die automatische Erkennung und Synthese von Grenzregeln (Boundary Laws) im Unified Mandala.

## Kernideen
- **Boundary Discovery Agent** analysiert Diskontinuitäten und leitet Regeln ab.
- **Boundary Law Manifest** sammelt erkannte Regeln als YAML-Dateien.
- **MacroSynthesizer** erzeugt übergeordnete Gesetzmäßigkeiten aus einzelnen Regeln.
- **Visualisierung** der Grenzregeln via MandalaCanvas.

## Nächste Schritte

2. Ausbau der `BoundaryLawDiscoveryEngine` zur Makro-Synthese.
