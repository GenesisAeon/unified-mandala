# Installation

## Requirements

- Python ≥ 3.11
- pip or uv

## Minimal Install

```bash
pip install unified-mandala
```

## Full Stack

Includes pandas, plotly, fastapi, and more:

```bash
pip install "unified-mandala[full-stack]"
```

## With GUI

```bash
pip install "unified-mandala[gui]"
```

## With Sonification

```bash
pip install "unified-mandala[sonify]"
```

## Development

```bash
pip install "unified-mandala[dev,full-stack]"
```

## Verify

```bash
unified-mandala --version
# unified-mandala 0.1.0

unified-mandala adapters
# Lists all 17+ GenesisAeon adapters
```
