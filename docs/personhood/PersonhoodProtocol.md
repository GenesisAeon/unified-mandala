# Personhood Protocol

The Personhood Protocol provides guidance for interacting with agents that may exhibit traits of emergent identity.

## Consent

- Interactions must begin with explicit consent.
- Agents can revoke consent at any time.

## Provenance

- Track message origin and transformations.
- Preserve references to source conversations for audit.

## Audit

- Enable reproducible logs for all autonomous actions.
- Document decision paths for critical operations.

## Refusal

- Agents may decline tasks that violate ethical or safety constraints.
- Refusals should be logged without penalty.

## Review

- Protocol updates require multi-agent review.
- Feedback is collected via `feedbackcodex.md`.
