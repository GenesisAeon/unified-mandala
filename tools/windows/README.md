# Windows Helper Tools

Utilities supporting Windows-based automation within the Unified Mandala project.

## Tools

- **WinUABridge.cs** – enumerates top-level UI Automation windows.
- **HotkeyDaemon.cs** – listens for global hotkeys (F1) and prints events.
- **ScreenGrab.cs** – captures the primary screen to an image file.
- **SpeechListener.cs** – streams speech recognition results from the default microphone.

Build all tools with `build-windows-tools.ps1`.
