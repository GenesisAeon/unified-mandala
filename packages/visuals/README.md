# Visuals

Graph and diagram utilities for Mandala data.

## Key modules
- `MandalaGraph.ts` – loads mastercanvas YAML and builds a Three.js scene.
- `ResonanzMandala.ts` – placeholder for resonance topology calculations.

## Basic usage
```ts
import { loadMasterCanvas } from '@unified-mandala/visuals';
```

Check `__tests__/MandalaGraph.test.ts` and `__tests__/ResonanzMandala.test.ts`.
