# Tutorials

Collection of learning modules for newcomers.
Includes **C-Tutor** and **JavaHamsterAI**, each with its own README.

## Key modules

- `C-Tutor` – tracks milestone progress (`CTutorProgress`).
- `JavaHamsterAI` – gamified hamster courses (`JavaHamsterFlow`).

## Basic usage

```ts
import { CTutorProgress } from '@unified-mandala/tutorials/C-Tutor';
```
